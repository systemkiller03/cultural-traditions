About this project

About the university project

Student ID: 000123
Email: student000123@wiut.uz

This project explores how design can support cultural storytelling without distracting from the traditions themselves. The aim was to present three very different cultural settings in a way that feels clear, respectful, and visually engaging.

  • The selected traditions focus on food, ritual, etiquette, music, and public gathering.
  • Each country page keeps the same layout idea while shifting mood through color and imagery.
  • Sources, images, and embedded media were chosen to make the cultural context easier to understand.

Project Info

Focus of the submission

Purpose

The project compares how traditions remain meaningful when they are tied to place, repeated over time, and experienced together.

Structure

Five linked pages were built from the approved lo-fi wireframes so that the final result stays close to the original layout plan.

Content

The country pages combine narrative text, tables, images, and video to present each tradition from more than one angle.
